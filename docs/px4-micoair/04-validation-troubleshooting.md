# 验证、首次试飞与排障

[返回目录](README.md)

## 1. 分阶段验收

| 阶段 | 操作 | 通过条件 | 不通过时 |
| --- | --- | --- | --- |
| 供电 | 拆桨、检查接线和供电轨 | 极性正确、无异常温升、电压符合规格 | 立即断电，先处理硬件 |
| 姿态 | 手动倾斜机体，观察地面站 | 姿态变化与实际一致，传感器无未解释告警 | 检查方向、校准和振动 |
| 遥控 | 检查各摇杆和开关 | 通道、方向、模式、解锁逻辑正确 | 排查协议与映射 |
| 动力 | 无桨逐路低输出测试 | 实际位置、逻辑编号和旋向一致 | 重做输出分配或电调设置 |
| 光流 | 量程内平移、上下移动 | 测距、方向和质量符合实际 | 排查供电、协议、安装和地面 |
| 估计 | 检查状态和日志 | 所需局部位置/速度及高度有效 | 查融合条件与创新，不放宽检查掩盖问题 |
| 保护 | 无桨验证模式及遥控丢失提示 | 预期动作与实际场地/导航能力相容 | 调整并复核保护策略 |

以上是本指南的验收框架；每台飞机须填写自己的结果，并不是本文已经替你测试通过。执行器操作参考 [PX4 Actuators](https://docs.px4.io/v1.16/en/config/actuators)。

## 2. 首飞前

1. 保存当前参数、连接照片和设置记录，确认 SD 卡可以记录 ULog。
2. 退出电机测试，关闭测试开关，断开电池和 USB；再次核对螺旋桨旋向、安装面、紧固和间隙后装桨。
3. 选择允许飞行且有隔离空间的场地。光流测试需有固定纹理、足够光照和平整地面，飞行高度处于该型号可靠量程内。
4. 确认遥控链路、人工接管方式、电池状态、解锁检查和模式要求。Position 模式需要有效的导航估计；不能仅根据“GPS 无信号”判断光流是否可用。
5. 事先决定出现漂移、姿态异常、振荡、测距丢失或链路故障时的处置，并由熟练操作者负责。

参考 [PX4 Position 模式](https://docs.px4.io/v1.17/en/flight_modes_mc/position)、[失效保护配置](https://docs.px4.io/v1.17/en/config/safety) 和 [官方首飞指南](https://docs.px4.io/main/en/flying/first_flight_guidelines)。首飞指南的 main 页面会更新，实际操作应选与本机固件相符的版本。

## 3. 首次离地

- 初次离地保持短时、低速和小范围，选择在光流/测距可靠范围且已离开明显近地干扰的高度；具体高度由机型、传感器、场地及操作者确定，不给所有飞机统一数值。
- 首先观察姿态、声音、电压、航向和基本控制是否正常，再验证定点保持。基础控制有问题时不继续进行光流或自动模式试验。
- 出现明显倾倒、急剧自旋、振荡或失控趋势，按预案处置并结束试验；避免在狭小室内临时探索模式切换或满油门拉升。
- 不在自由飞行中主动拔掉传感器或关闭遥控来测试保护。不拿手抓持装桨飞机测试推力，也不把简单绑绳当作万能安全试验台。
- 落地停桨后断开电池，检查电机/电调温升、焊点、连接器、紧固件和电池固定；保存日志后再决定下一次试验内容。

## 4. 故障速查

| 现象 | 优先检查 | 避免的误操作 |
| --- | --- | --- |
| QGC 无法连接 | 数据线、USB/驱动、板卡启动状态、固件目标、是否被其他软件占用 | 未确认型号就反复刷其他板固件 |
| 飞控有连接，光流无数据 | 外设电源、TX/RX 交叉、共地、物理 UART 映射、模块协议、波特率 | 把 12V/VBAT 改接到 5V 模块 |
| 只有测距消息 | USB 下复查、模块协议与版本、飞控数据链路限速 | 只看数传界面就认定光流损坏 |
| 电机全不转 | 电池是否供电、协议、输出组、解锁/测试流程、信号地 | 装桨后提高输出排查 |
| 只一个电机异常 | 该路焊点、相线、输出映射、电调通道与电机 | 带电换线或继续长时间堵转 |
| 起飞倾倒或急剧自旋 | 立即结束试验，再查电机编号、旋向、桨叶和飞控方向 | 第一反应就大改 PID |
| 能定高却不能定点 | 光流质量、测距、坐标方向、融合状态、有效局部位置、航向 | 关闭解锁/位置检查强行起飞 |
| 定点持续漂移或绕圈 | 地面/光照、安装变换、磁干扰、日志中的速度/航向/创新 | 只凭漂移方向修改不明参数 |
| 高度跳变 | 地面台阶、遮挡、反射、量程、供电、高度参考源 | 把测距高度参考用于所有地形 |
| 重启后设置不对 | 参数是否保存、固件/机型重置、选错 MAVLink 实例或端口 | 在不备份情况下反复全参数恢复 |

光流、测距和估计器的诊断依据见 [光流配置](03-optical-flow.md) 及其中原厂来源。

## 5. 每次只改一个问题

记录“现象 → 日志/证据 → 假设 → 单项修改 → 复测结果”。如果无法解释具体设置的作用，保留原值与来源，先查文档。升级固件、改变接线、调整机架构型或更换动力后，应重新走受影响的验收步骤。
