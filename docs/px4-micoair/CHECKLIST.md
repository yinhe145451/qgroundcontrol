- [ ] 记录飞控、电调、光流完整型号及硬件版本。

- [ ] 焊接、极性、短路与供电轨检查完成，无异常温升。
- [ ] 下视镜头与测距窗无遮挡，安装方向已记录。

## 固件与基础设置

- [ ] PX4 目标与板卡匹配，已记录完整版本和下载来源。
- [ ] 机型及飞控朝向正确，倾斜机体时地面站姿态一致。
- [ ] 陀螺仪、加速度计、水平与磁力计按需要校准。
- [ ] 遥控通道、端点、方向、模式与解锁开关经过确认。
- [ ] 电池监测与实际电压一致，电流来源/比例已核对。
- [ ] 四路电机的位置、逻辑编号与转向经无桨测试一致。
- [ ] 参数重启后保留，并已导出备份。

## 光流与估计

- [ ] 模块协议与 PX4 匹配，MAVLink 实例和物理串口对应正确。
- [ ] 测距在有效范围内随真实距离变化，单位核对正确。
- [ ] 光流在有纹理、光照足够的地面上有合理质量与运动响应。
- [ ] 模块和飞控的旋转设置未重复补偿，坐标方向已检查。
- [ ] EKF 的融合及所需局部位置/速度、高度、航向有效。
- [ ] 高度源选择适合场地、地面起伏与测距量程。
- [ ] 光流/测距失效的处置计划已确定；未关闭安全检查掩盖问题。

- [ ] 退出电机测试并断电后装桨，旋向、安装面和固定正确。
- [ ] 电池、线束、天线和机架固定，桨盘范围内无松散物。
- [ ] SD 卡/日志可用，当前参数和接线照片已保存。
- [ ] 场地允许、空间及人员隔离满足要求，有熟练操作者接管。
- [ ] 返航/降落等保护行为符合该环境与导航能力。
- [ ] 无未解释的传感器、定位、遥控、电源或解锁告警。
- [ ] 本次试验目标、终止条件和落地检查已明确。
